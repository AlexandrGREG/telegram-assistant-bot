# Telegram Assistant Bot 🤖

Персональний помічник, асистент у Telegram, який дозволяє і допоможе створювати, зберігати, переглядати нотатки та більше.

## Можливості
- ✅ Додавання нотаток
- 📝 Перегляд і видалення
- ✏️ Структура FSM для послідовного введення
- 📎 Кнопки для взаємодії

## Стек
- Python 3.10+
- aiogram 3.x
